Demo host page

Stands in for an arbitrary cowabungavegas.com page. The popup fires on a timer (default 6s) and loads its own CSS (cowabunga-popup.css) and its own fonts (Luckiest Guy / Grandstander / Quicksand) rather than assuming the host page already has either — see cowabunga-popup.js's ensurePopupCssLoaded()/ensureFontsLoaded(). This page doesn't link cowabunga-popup.css itself; that's the point being demonstrated.

Uses window.COWABUNGA_POPUP_CONFIG.delayMs = 2000 below so it fires quickly for testing without feeling instant; production embeds should leave the default (6000ms) or set their own.
